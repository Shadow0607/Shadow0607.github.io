IG AI Vision System

分散式微服務架構的社群媒體爬蟲與 AI 視覺辨識系統

ASP.NET CorePythonVue 3 MySQLRedisMinIOQdrant

GitHub Repo ↗

概述

自動化採集 Instagram / YouTube 等社群平台的媒體資源，透過深度學習模型進行人臉辨識與歸檔。系統分為五個區塊：基礎設施、Python 爬蟲端（Producer）、Python AI 分析端（Consumer）、.NET 後端 API 與 Vue 3 前端。

處理流程

S1 爬蟲下載→pHash + MD5 去重→上傳 MinIO→ Redis Queue→S2 人臉特徵擷取→Qdrant 向量比對→ OUTPUT / PENDING / REJECTED

系統組成

區塊技術職責
基礎設施Docker Compose：MySQL 8、Redis 7、MinIO、Qdrant、Geth資料儲存、訊息佇列、物件儲存、向量資料庫、私有鏈上鏈備查
S1 爬蟲服務Python依監控清單下載貼文與限時動態、雙指紋去重、發佈處理任務；來源不明確者移入隔離區
S2 AI 辨識服務Python、RetinaFace / MTCNN多執行緒消費任務、擷取人臉特徵、比對分數後自動分類並更新狀態
後端 APIASP.NET Core、EF Core、SignalR、JWTRSA JWT 認證的 REST API、媒體服務、即時推播 Worker 進度、背景佇列監控
前端Vue 3 + Vite、Axios、SignalR監控儀表板、進度與報表、人工審查介面
